## 2. Cloning the repository

Open a terminal and run:

```bash
git clone https://github.com/Soumyo42/PDE-informed-Co-Kriging.git
cd PDE-informed-Co-Kriging
```

To obtain later updates:

```bash
git pull
```

## 3. Minimal Python installation

### Requirements

```text
Python version used by the authors: 3.12.2
```

### Create a python virtual environment (Completely optional)

Using Python's built-in `venv` module:

```bash
python -m venv .venv
```

Activate the environment on Linux or macOS:

```bash
source .venv/bin/activate
```

Activate it on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Upgrade `pip`:

```bash
python -m pip install --upgrade pip
```

### Install the package requirements

Install the dependencies with:

```bash
python -m pip install -r requirements.txt
```

Principal dependencies below: 

```text
NumPy: 2.5.4
SciPy: 1.18.1
PyTorch: 2.6.0
Matplotlib: 3.11.2
Other dependencies: sympy, Shapely
```

## 4. Running the examples

Run all commands from the repository root. Most python files should have the optimized parameters already.  

```bash
python <INSERT FILE NAME>.py
```

## 8. Troubleshooting

### `ModuleNotFoundError`

Confirm that the virtual environment is active and install the repository from its root:

```bash
python -m pip install -e .
```

Then rerun the command from the repository root.

### Output directory does not exist

Create it before running the experiment if the script does not create it automatically:

```bash
mkdir -p figures
```

On Windows PowerShell:

```powershell
New-Item -ItemType Directory -Force figures
```
